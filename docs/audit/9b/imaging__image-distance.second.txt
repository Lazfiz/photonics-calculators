Model

1/o + 1/i = 1/f, i = f·o/(o − f), M = −i/o

From M: o = f(1 − 1/M), i = f(1 − M)

Newtonian: x·x′ = f², x = o − f, x′ = i − f

Paraxial thin lens in air, real-is-positive signs: o > 0 for a real object in front of the lens, i > 0 for a real image behind it, f > 0 for a converging lens. An object inside the focal length of a converging lens gives a virtual, upright, enlarged image (a magnifier); a diverging lens always gives a virtual, upright, reduced one. The real object-to-image distance is shortest, 4f, at M = −1.

MODEL AND REFERENCES

Textbook approximation. A standard approximation from the literature (for example paraxial, plane-wave or Gaussian-beam), valid within the range the page states. About the tiers
