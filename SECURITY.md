# Security

Please report a security problem privately, not in a public issue: use
[GitHub's private vulnerability reporting](../../security/advisories/new) for this repository.

The site is static apart from three endpoints: the calculator API (`/api/v1/<category>/<slug>`), the MCP endpoint (`/mcp`) and the
problem-report form (`/api/report`). Reports about those are especially welcome.

A wrong calculation result is not a security issue: report it as a
[physics or calculation error](../../issues/new?template=physics-error.yml).
